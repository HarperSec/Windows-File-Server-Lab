
# Windows File Server Lab

## Overview

This project demonstrates how to deploy and secure a Windows Server file server using Active Directory security groups, NTFS permissions, and SMB shared folders.

The objective is to simulate a real-world business environment where different departments require secure access to shared resources while following the Principle of Least Privilege.


## Objectives

- Deploy a Windows file server
- Create departmental shared folders
- Configure NTFS permissions
- Configure SMB share permissions
- Create Active Directory security groups
- Assign users to security groups
- Validate user access
- Troubleshoot permission-related issues


## Technologies Used

- Windows Server 2025
- Active Directory Domain Services (AD DS)
- NTFS File System
- SMB File Sharing
- VMware Workstation


## Skills Demonstrated

- Windows Server Administration
- File Server Administration
- Identity and Access Management (IAM)
- Access Control
- NTFS Permissions
- Share Permissions
- Active Directory Security Groups
- Principle of Least Privilege
- Troubleshooting
