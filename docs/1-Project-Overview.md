# Windows File Server Lab - Project Overview

## Purpose

This project simulates a small business Windows file server environment. The goal is to practice managing shared resources, user access, security groups, and permissions using Windows Server.

## Scenario

A company requires centralized file storage for different departments. Each department needs access to its own shared folders while preventing unauthorized access.

## Objectives

- Create department-based file shares
- Configure security groups
- Apply NTFS permissions
- Configure share permissions
- Test user access
- Troubleshoot permission issues

## Lab Environment

- Hypervisor: VMware Workstation Pro
- Operating System: Windows Server
- Server Role: File Server
